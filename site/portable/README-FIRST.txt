OPEN PICKLEBALL TOURNEY - OFFLINE COPY

1. Unzip this folder. Leave it where you put it (Documents or Desktop is fine).
2. Open the folder and double-click "index.html". It opens in your web browser.
   You do not need the internet.
3. Click "Try a practice tournament" first to see how it works.

Good to know
- Your tournament is saved inside that web browser on that computer. Use the
  same browser each time.
- Moving or renaming this folder, or using a different browser, shows an empty
  tournament. Click "Download a copy" now and then, and "Open a saved copy" to
  bring a tournament back.
- To show it on a big screen or board, open index.html on the computer that is
  connected to it and press F11 (Windows) or Control+Command+F (Mac) for full
  screen.
- Printing works from the page: "Print schedule" and "Print results".
- Putting this folder on a web server for other devices: use an https:// address
  (or http://localhost on that same computer). Plain http:// addresses cannot
  save automatically.
- Updates: download a fresh offline copy from the website and open it. Use
  "Download a copy" first if you want to bring an event across.
