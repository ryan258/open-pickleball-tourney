Architecture Note: Dynamic Django Application

Open Pickleball Tourney is a full-stack Python 3.13 / Django 5.2 LTS application with immediate transactions, durable outbox message delivery, and role-based access. While this documentation portal is hosted statically on GitHub Pages, the actual tournament management runtime runs either locally on your laptop or hosted on any Python WSGI/PaaS platform.

Tournament Capabilities

Engineered for Event-Day Reality

Designed around common tournament pitfalls: spotty Wi-Fi, last-minute partner changes, rest intervals, and paper fallbacks.

🎯

Seeded Draws & Round-Robins

Deterministic bracket generation including single elimination, double elimination with optional reset match, and snake-seeded pool play.

⚡

Live Court Scheduling

Automated conflict detection: enforces player rest intervals, prevents double-booking, and handles court suspensions immediately.

📄

Printable Recovery Pack

One-click export of an event revision pack with match codes and paper scoring grids. If power or Wi-Fi fails, play continues without hesitation.

👥

Doubles Partner Consent

Both partners must explicitly accept their invitation. Prevents phantom entries and secures accurate check-in records.

🔒

Scoped Scorer Access

Umpires and volunteers receive scoped match PINs. They can only record authorized match scores without accessing event settings or financial data.

💾

Data Sovereignty

Export full JSON/CSV event archives and SQLite snapshots anytime. No proprietary lock-in or subscription gates.

Quickstart

Run or Deploy in Minutes

Choose your environment: run the interactive local demo, serve on your LAN, or host in the cloud.

Interactive Organizer Demo

Launches an isolated synthetic event with 32 players, 16 doubles teams, 4 courts, and 24 round-robin matches. No password required.

Terminal 
# Clone the repository
$ git clone https://github.com/ryan258/open-pickleball-tourney.git
$ cd open-pickleball-tourney

# Start the demo (migrates isolated DB, starts mail worker, opens on 127.0.0.1:8000)
$ ./tour

Then open http://127.0.0.1:8000 and click Open organizer demo.

Your Own Local Event

Run your club's actual tournament locally. Starts the server and background worker without demo data.

Terminal 
# Start local tournament service
$ ./tour serve

# In another terminal, generate your private 15-minute organizer link
$ .venv/bin/python manage.py organizer_link you@example.org

Cloud Deployment (PaaS / Docker / VPS)

Deploy to Render, Fly.io, Railway, or any Linux server using Gunicorn and PostgreSQL.

Bash 
# Environment configuration (.env)
DATABASE_URL=postgresql://user:password@host:5432/tourney
SECRET_KEY=<generate-random-secret>
DEBUG=0
ALLOWED_HOSTS=tourney.yourdomain.org

# Run migrations & collect static assets
python manage.py migrate --noinput
python manage.py collectstatic --noinput

# Start WSGI server & Outbox worker
gunicorn config.wsgi:application --bind 0.0.0.0:8000
python manage.py work_outbox

Deterministic SQLite Backups

Create consistent SQLite snapshots with cryptographic SHA-256 manifests and restore with automatic verification.

Terminal 
# Create verified snapshot archive
$ .venv/bin/python manage.py backup_local --output .data/backups/event-day.tar.gz

# Restore into a separate verified directory
$ .venv/bin/python manage.py restore_local .data/backups/event-day.tar.gz --output-dir .data/restored-event-day
Operations

The 7-Step Tournament Lifecycle

From initial division setup to final certified results export.

Step 01

Configure Event

Set divisions, capacity limits, court hours, and scoring rules (rally scoring, win-by-2).

Step 02

Registration

Register participants with individual links. Doubles partners independently verify acceptance.

Step 03

Check-In Desk

Record player arrival and accommodations. Generate and review the seeded draw preview.

Step 04

Court Proposals

Commit court assignments. The engine validates player rest and court availability automatically.

Step 05

Score Recording

Scorers enter game scores. Retirement records partial games cleanly without breaking dependent brackets.

Step 06

Certify Divisions

Finalize completed divisions or mark interrupted play as partial with full audit logs.

Step 07

Export & Portability

Download public standings, private event archives, or clean roster CSV packages.
