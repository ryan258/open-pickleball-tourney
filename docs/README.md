# Documentation & Reference

This directory contains reference documentation for the Open Pickleball Tourney project.

## Documents

- [`101-really-good-pickleball-rules-questions-w-answers.md`](101-really-good-pickleball-rules-questions-w-answers.md): Comprehensive rules Q&A reference cross-referenced against the 2026 USA Pickleball Official Rulebook, detailing the casual house rules differences implemented by this application.

  - [`site/README.md`](../site/README.md): Full browser edition documentation, organizer workflows, format rules, and build/test commands.

  - [roadmap.md](../roadmap.md): Evolution, recent updates, and future directions.
  - [IMPLEMENTATION.md](../IMPLEMENTATION.md): Evidence, benchmarks, and verification limits.

- **Archived Django Edition (`django-edition/`):**
